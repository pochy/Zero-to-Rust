管制:

```text
config 層:
環境変数と設定値。

error 層:
エラー分類。
```

管制:

「エラー処理」

マーク:

```text
不正コマンド:
ERROR を返す。

存在しないキー:
NOT_FOUND。

I/O エラー:
Result で上位へ。

WAL 書き込み失敗:
整合性方針に従う。原則、更新前に失敗。

クライアント切断:
その接続を閉じる。サーバー全体は落とさない。

ロック取得失敗:
poison を分類し、復旧または停止を判断する。

TTL 期限切れ:
読み取り時またはクリーンアップで削除する。
```

管制:

「セキュリティ」

マーク:

```text
bind address を設定可能にする。
最大コマンド長を制限する。
最大キー長を制限する。
最大値サイズを制限する。
管理 HTTP は localhost 限定にする。
ログに値本体を出さない。
不正入力で panic しない。
```

管制:

「救助可能か」
